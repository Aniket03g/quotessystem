Page 5

➕ Creating a New User

1
Navigate to User Management
Click "Admin" → "Users" in the navigation menu
2
Click "Create User" Button
Located at the top right of the users page
3
Fill in User Details
• Email address (required)
• Full name
• Role (Admin or User)
4
Submit and Get Temporary Password
System generates a secure temporary password - share this with the new user securely
🔒 Security Note: The temporary password is shown only once. Users must change it on first login.
Page 6

⚙️ Managing Existing Users

View All Users

The users list shows: Email, Name, Role, Provider (local/OAuth), Password Change Status, and Creation Date

Reset User Password

Steps:

  • Click "Reset Password" button next to the user
  • Confirm the action
  • Copy the new temporary password
  • Securely share with the user (email, secure message, etc.)

User Status Indicators

• Must Change Password: User needs to update their temporary password
• Provider: Shows if user logs in via local account or OAuth (Google/GitHub)

📄 Quote Management Overview

Quotes are the core business documents in the CRM. Admins can view and manage all quotes in the system.

What Admins Can Do:

  • View all quotes from all users
  • Create new quotes
  • Edit existing quotes
  • Generate PDF versions
  • Track quote status
  • Create quote versions

Quote Information:

  • Quote number and subject
  • Associated account
  • Products and pricing
  • Quote date and validity
  • Status (Draft, Sent, Approved, Final)
  • Total amount
Page 8

📝 Creating a Quote - Account Selection

1
Navigate to Quotes
Click "Quotes" in the navigation menu, then "Create Quote" button
2
Search and Select Account
• Type customer/company name in the search box
• System searches existing accounts
• Select the appropriate account from dropdown
3
Account Details Auto-Populate
Once selected, the following fields fill automatically:
• Company Name
• Phone Number
• Billing Street and City
• Shipping City
💡 Tip: If the account doesn't exist, create it first via "Accounts" → "Add Account"
Page 9

📝 Creating a Quote - Quote Details

4
Set Quote Dates
• Quote Date: Defaults to today (can be changed)
• Valid Until: Defaults to 30 days from today (can be changed)
5
Select Quote Status
• Draft: Quote is being prepared
• Sent: Quote has been sent to customer
• Approved: Customer has approved the quote
• Final: Quote is finalized
6
Choose Quote Type
• Customer: Uses customer pricing
• Dealer: Uses dealer pricing (typically lower)
⚠️ Important: Quote type determines which product prices are used. Choose carefully!
Page 10

📝 Creating a Quote - Adding Products

7
Search for Products
Type product name in the search box - system shows matching products with prices
8
Select Product
Click on the desired product - details auto-populate:
• Brand, Product Code, HSN Code
• Model, Tax Rate, Description
• Unit Price (based on quote type)
9
Adjust Price and Quantity
• Modify unit price if needed (for discounts/negotiations)
• Set quantity required
10
Add Multiple Products
Click "Add Product" button to add more items to the quote
Page 11

📝 Creating a Quote - Finalizing

11
Add Notes (Optional)
Include any additional terms, conditions, or special instructions
12
Review Quote
Double-check all information:
• Account details are correct
• Products and quantities are accurate
• Prices are appropriate
• Dates are set correctly
13
Submit Quote
Click "Create Quote" button - system calculates totals and saves the quote
✅ Success: After creation, you'll be redirected to the quote detail page where you can view, edit, or generate PDF.

📦 Product Catalog Management

The product catalog contains all items available for quotes.

Product Information Includes:

  • Product Name: Clear, descriptive name
  • Brand: Manufacturer or brand name
  • Product Code: Internal SKU or product code
  • HSN Code: Tax classification code
  • Model: Specific model number
  • Tax Rate: Applicable tax percentage
  • Description: Detailed product description
  • Customer Unit Price: Standard customer pricing
  • Dealer Unit Price: Dealer/wholesale pricing
💰 Pricing Strategy: Maintain two price tiers (Customer & Dealer) for flexible quote generation.

✨ Best Practices for Administrators

🔐 Security

• Use strong passwords and change them regularly
• Never share admin credentials
• Review user access periodically
• Ensure temporary passwords are changed promptly

📊 Data Management

• Keep account information current and accurate
• Regularly update product pricing
• Maintain consistent naming conventions
• Archive old quotes appropriately

👥 User Support

• Provide training to new users
• Respond promptly to password reset requests
• Monitor system usage and address issues
• Document common procedures

🔧 Troubleshooting Tips

User Can't Login

• Verify account exists in user management
• Check if password needs to be reset
• Ensure user is using correct email address
• Verify account is not locked

Quote Not Saving

• Check all required fields are filled
• Verify account is selected
• Ensure at least one product is added
• Check for valid dates

PDF Generation Issues

• Verify quote has all required information
• Check product details are complete
• Ensure account information is present
• Try refreshing the page and regenerating
