Administrator Guide — User Creation & Management
Admin Role Required Version 1.0 June 2026
1

Before You Begin

Requirement
You must be logged in with an Admin account to create or manage users. Regular user accounts will be redirected away from the user management page.

Open your browser and navigate to:

https://crm.grovesystems.co/admin/users
2

Creating a New User

1
Click "Create User"

The button is in the top-right corner of the User Management page. The user list will slide out and a form will appear.

2
Fill in the form

Complete the fields below, then click Create User.

Field Required Notes
Full Name Optional Display name shown in the user list
Email Address Required Must be unique — duplicate emails are rejected. This cannot be changed after creation.
Role Required Select User for standard access, or Admin for full access. See Section 4 for details.
Password — Auto-generated by the system. You do not enter one.
3
Copy the temporary password

A green success card will appear showing the new user's email, role, and their temporary password. Click the Copy button to copy it.

4
Share the password securely

Send the temporary password to the user via a secure channel (WhatsApp, encrypted email, etc.). Do not send it over plain unencrypted email or SMS if avoidable.

⚠  Important — Password Shown Once Only
The temporary password is displayed immediately after creation and never again. If you close the screen without copying it, you will need to use Reset Password to generate a new one.
3

What the New User Does on First Login

Share these steps with the new user so they know what to expect.

1
Open the CRM login page

Go to https://crm.grovesystems.co/login

2
Log in with the temporary password

Enter their email address and the temporary password you shared with them.

3
Change password when prompted

The system will automatically show a Change Password screen. They must set a new password (minimum 6 characters) before they can use the CRM. They will enter:

  • Old Password — the temporary password just used to log in
  • New Password — their chosen permanent password (min. 6 characters)
4
Access is granted

After changing the password, they are logged in and can use the CRM normally.

✓  After First Login
Once the user changes their password, their status in the admin user list changes from "Password Reset Required" to "Active".
4

User Roles

👤  User

  • Access all CRM data (leads, quotes, products, accounts, contacts, cases)
  • Create and edit records
  • Generate quote PDFs
  • Cannot access user management
  • Cannot create other users

🛡  Admin

  • Everything a User can do
  • Access /admin/users
  • Create new users
  • Reset any user's password
  • Bypasses all data access restrictions
⚠  Be Careful with Admin Role
An Admin account has unrestricted access to all data and can manage all other users, including other Admins. Assign the Admin role only to people who need to manage the system.
5

Resetting a User's Password

Use this when a user is locked out or has forgotten their password.

1
Go to User Management

Navigate to /admin/users and find the user in the table.

2
Click "Reset Password"

This is in the Actions column next to the user's row.

3
Confirm and copy

A modal will ask you to confirm. After confirming, a new 16-character temporary password is generated and shown in the modal. Copy it and share it with the user.

4
User changes their password on next login

The same first-login flow applies — they must set a new password before accessing the CRM.

6

Understanding User Status

Active
User has set their own password and can log in normally.
Password Reset Required
User was just created or had their password reset by an admin. They must change their password on next login.
7

Common Issues

Issue Cause Solution
"User with this email already exists" The email address is already registered Check the user list — the account may already exist. Use a different email if this is a new person.
User cannot log in after creation Wrong password shared, or copied incorrectly Use Reset Password to generate a new temporary password and share it again.
User sees "Change Password" every login They skipped the password change step The user must complete the password change. They cannot bypass it.
Cannot access /admin/users Logged in with a User role account Log in with an Admin account, or ask an existing admin to promote your account.
