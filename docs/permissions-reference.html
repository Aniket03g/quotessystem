Enforcement layers:
• Go proxy (backend) — enforces authentication (JWT required) and allowed operations per table (proxy.yaml). No per-role blocking at the API level.
• Frontend (Astro) — all role checks are UI-side only. A user who calls the API directly bypasses them.
• Row-level filtering — currently disabled in authorize.go pending a created_by column in NocoDB.
• To make delete truly admin-only for accounts/quotes/contacts, add a role check in the respective .astro page (same pattern as leads.astro line ~1136).
