User Creation Guide

Grove CRM  ·  Admin Reference  ·  Updated June 2026

Overview

Fully automated. When you create a user, the system generates a secure temporary password and emails it directly to the user. No manual password sharing needed.

Steps to Create a User

1

Go to Admin Panel

Log in as an admin and navigate to /admin/users from the sidebar. Only admins can access this page.

2

Click "Create User"

Click the Create User button in the top right. The user creation form will open.

3

Fill in the details

Enter the user's Full Name, Email Address, and select their Role (User or Admin). The password is auto-generated — you don't set it.

4

Click "Create User"

The system will create the account and automatically send an invitation email to the user. The button shows "Creating User…" then "Sending Invitation…" while it works.

5

Done — user receives email

A success card confirms "Invitation email sent". The user gets an email (see preview below) with their login credentials and a direct link to the CRM.

If email delivery fails — the success card will show an amber warning with the temporary password visible so you can share it manually.

User's First Login

1

Click the login link in the email

Or go to the CRM URL directly and enter their email and temporary password.

2

Forced password change

On first login, the system immediately redirects to a Change Password screen. The user must set a new password before they can access anything.

3

Access granted

Once the password is changed, the user is logged in and can use the CRM normally.

Roles

Resetting a User's Password

If a user forgets their password, go to /admin/users, find the user in the table, and click Reset Password. The system will generate a new temporary password and email it to the user automatically — same flow as creation. The user must change it on next login.

Reset email comes from: admin@grovesystems.co  ·  Quote emails come from: a separate quotes address — the two are kept distinct.
