Grove Systems CRM

Quick reference guide for all users

Regular User Admin
Getting Started

Login

  • Enter your email and password
  • You'll land on Quotes (or Dashboard if admin)
  • First login forces a password change

Your Role

  • User — own leads + assigned leads only
  • Admin — all leads, all users, full access
  • Admins see Dashboard + User Management in sidebar
Leads

What you can do

  • View, search, and filter leads
  • Create a new lead
  • Edit lead details and status
  • Convert a lead to an Account
  • Delete Admin

Filters available

  • Search by name, company, phone, email
  • Filter by Status
  • Filter by Source
  • Filter by Assigned To

Lead Status Flow

New → Contacted → Qualified → Proposal Sent → Negotiation → Converted / Lost
Overdue follow-ups appear in red. Users only see their own leads; admins see everyone's.
Convert to Account and Delete are only available to the lead's creator or an admin.
Quotes

Creating a Quote

  • Select an Account (customer)
  • Add products from the catalogue
  • Total is calculated automatically
  • Set status to Draft to start

Quote Actions

  • Edit products and quantities
  • Create a new version (on revision)
  • Preview and download as PDF
  • Choose Grove or GreenOCare branding
Each revision should be saved as a New Version — this keeps the full quote history intact.
Accounts & Contacts

Accounts

  • Represent companies you work with
  • Linked to quotes and contacts
  • Can be created manually or by converting a lead
  • Account detail shows all linked quotes and contacts

Contacts

  • Individual people inside an account
  • Must be linked to an account
  • Can be viewed, added, edited, or deleted
Products & Cases

Products

  • Read-only catalogue — no editing here
  • Shows name, brand, price, HSN, tax, status
  • Contact admin if a product is wrong or missing

Cases

  • Group related quotes under one case
  • Statuses: Open, Won, Closed
  • Expand a case to see linked quote timeline
Admin Only

User Management

  • Create users (name, email, role)
  • System generates a temporary password
  • Share temp password — user must change it on first login
  • Reset any user's password from the user list

Full Leads Access

  • See all leads from all team members
  • Filter by Assigned To for individual views
  • Reassign leads to any user
  • Delete any lead

Dashboard

  • Total users, quotes, products count
  • System health status
  • Quick links to key sections
Copy the temporary password immediately after creating a user — it is only shown once.
